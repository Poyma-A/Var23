# Вариант 23

CLI для анализа зависимостей Maven.
Python 3.10 или новее.

Передайте в `--package` координаты
`groupId:artifactId:version`, а в
`--repository` базовый URL Maven.
Параметр `--max-depth` обязателен.

`make test` запускает тесты.

В тестовом режиме передайте
`--test-mode on` и
`--repository tests/graph.txt`.
Каждая строка файла содержит имя
пакета и его прямые зависимости
через пробел. Имена состоят из A–Z.
Пакет A включает цикл, E — цепочку.
Задайте `--max-depth 1`, чтобы
оставить один уровень, или
`--filter B`, чтобы исключить B.

На этапе 4 ключ `--load-order`
печатает зависимости перед пакетами,
которые их используют. Для E из
тестового файла результат G F E.
Для A программа сообщает о цикле.

Для сравнения Maven 3.9.11 запускался
с `dependency:tree` на проекте с
зависимостью `junit:junit:4.13.2`.
Maven включает Hamcrest Core 1.3.
CLI также показывает Hamcrest Library
1.3 из POM JUnit. У неё scope test,
и Maven исключает её при разрешении
транзитивных зависимостей проекта.
Дерево Maven показывает связи.
Порядок CLI ставит листья перед JUnit
и не описывает сетевые загрузки Maven.
