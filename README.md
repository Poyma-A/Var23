# Вариант 23

CLI для анализа зависимостей Maven.
Python 3.10 или новее.

Передайте в `--package` координаты
`groupId:artifactId:version`, а в
`--repository` базовый URL Maven.
Параметр `--max-depth` обязателен.

`make test` запускает тесты.

В тестовом режиме передайте
`--test-mode on` и
`--repository tests/graph.txt`.
Каждая строка файла содержит имя
пакета и его прямые зависимости
через пробел. Имена состоят из A–Z.
Пакет A включает цикл, E — цепочку.
Задайте `--max-depth 1`, чтобы
оставить один уровень, или
`--filter B`, чтобы исключить B.
